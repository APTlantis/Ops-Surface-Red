# Superseded Tauri Scaffold

The former React/TypeScript/Vite/Tauri scaffold was retired on 2026-09-05 when the project was rebooted in Red.

The surviving frontend source and dependency manifests are retained under `legacy/tauri-scaffold/` only as recoverable historical material. They are not part of the active build, carry no implementation authority, and should not influence the Red architecture unless a specific behavior is deliberately recovered.

The archive did not contain the documented `src-tauri` Rust backend. Earlier Tauri build and Rust-test claims therefore remain historical statements from the project records, not reproducible evidence in this package.
